Spesifikasi Struktur Data & Arsitektur Backend Sistem

Aplikasi manajemen ini mengimplementasikan standarisasi logika pemrograman objek (OOP) dan algoritma manipulasi array mandiri pada berkas inti backend:

Pemrograman Berorientasi Objek (OOP)
Entitas entri data dari MySQL dibungkus penuh ke dalam model objek `Mahasiswa` melalui mekanisme Pewarisan (Inheritance) dari induk `Orang` serta Polimorfisme.
Algoritma Sorting Manual (Bubble & Selection)
Proses pengurutan prestasi IPK tertinggi diolah melalui struktur bersandar (nested loop) dengan kalkulasi parameter Running Time Complexity sebesar O(n²).
Algoritma Linear Searching Manual
Pencarian rekam data berdasarkan filter kata kunci NIM atau Nama dijalankan secara sekuensial dari awal array dengan nilai batas kompleksitas waktu O(n).
Validasi Pola Regex & Intersepsi Exception
Penyaringan manipulasi input data formulir diisolasi secara ketat menggunakan pencocokan Regular Expression guna menghindari cacat data (data corruption).
